# ملف الإنجاز المهني | د. أفنان الطلحي

منصة رقمية لملف الإنجاز والأداء الوظيفي، تقرأ محتواها مباشرة من مجلد Google Drive، فلا يُكتب فيها أي إنجاز أو وثيقة يدويًا داخل الكود.

**التقنيات:** Next.js 15 · TypeScript · Tailwind CSS · Framer Motion · خط Almarai · RTL كامل.

## الأقسام

| الصفحة | المصدر |
|---|---|
| الرئيسية `/` | واجهة افتتاحية + فهرس الأقسام بأعداد حقيقية + الإنجازات المضافة من اللوحة |
| مقدمة الملف `/intro` | المجلد الأول — مستندات Google Docs تُعرض نصوصها كما كُتبت (مع إبراز الرؤية والرسالة والأهداف) |
| ملف الأداء الوظيفي `/performance` | المجلد الثاني — كل مجلد فرعي قسم مستقل ببطاقات وثائق قابلة للمعاينة |
| البنود المطلوبة من المديرة `/requirements` | المجلد الثالث — كل مجلد فرعي «بند»، ويُعدّ مكتملًا إذا احتوى وثيقة منشورة واحدة على الأقل |
| الشواهد والوثائق `/library` | كل وثائق المجلدات الأربعة: بحث فوري، فلاتر بالنوع والمجال والتصنيف، معاينة PDF والصور داخل الموقع، وفتح الأصل في Drive |
| لوحة التحكم `/admin` | محمية بكلمة مرور |

يُربط كل قسم بمجلده تلقائيًا من اسمه (مقدمة / الأداء / المديرة / الشواهد) أو من ترتيبه، ويمكن تغيير الربط من اللوحة.

## خطوات التفعيل

### ١) ربط Google Drive (اختاري طريقة واحدة)

**الطريقة (أ) — الأسهل:**
1. من [Google Cloud Console](https://console.cloud.google.com/) أنشئي مشروعًا، وفعّلي **Google Drive API**، ثم أنشئي **API key** (يُفضّل تقييده بـ Drive API).
2. في Drive: شاركي مجلد «ملف الإنجاز والأداء الوظيفي» بخيار **«أي شخص لديه الرابط — مُشاهِد»**.
3. ضعي المفتاح في `GOOGLE_API_KEY`.

> الملفات التي تُلغى مشاركتها بالرابط تختفي من الموقع تلقائيًا.

**الطريقة (ب) — للتحكم الدقيق في الخصوصية:**
1. أنشئي **Service Account** في المشروع نفسه، ونزّلي مفتاحه JSON.
2. شاركي المجلد مع بريد حساب الخدمة كـ«مُشاهِد» (دون مشاركة عامة).
3. ضعي `GOOGLE_SERVICE_ACCOUNT_EMAIL` و`GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY`.

> في هذه الطريقة ترين كل الوثائق في لوحة التحكم، لكن **الزوار لا يرون إلا الوثائق المشاركة بالرابط**؛ فالوثائق الخاصة تبقى خاصة.

### ٢) لوحة التحكم
- `ADMIN_PASSWORD`: كلمة مرور قوية.
- `ADMIN_SESSION_SECRET`: نص عشوائي طويل (٣٢ حرفًا فأكثر).

### ٣) حفظ إعدادات اللوحة على Vercel
من مشروعك في Vercel ← **Storage** ← أضيفي **Upstash Redis** (مجاني)، وستُضاف المتغيرات تلقائيًا. محليًا تُحفظ الإعدادات في `.data/settings.json`.

### ٤) النشر
1. ارفعي المشروع إلى GitHub.
2. في [Vercel](https://vercel.com/new) استوردي المستودع، وأضيفي متغيرات `.env.example` في **Environment Variables**.
3. انشري. يتحدّث المحتوى كل ١٠ دقائق، أو فورًا من زر «تحديث المحتوى الآن» في اللوحة.

## التشغيل محليًا

```bash
npm install
cp .env.example .env.local   # ثم عبّئي القيم
npm run dev
```

## ما تتيحه لوحة التحكم
- حالة الربط مع Drive وعدد الوثائق الظاهرة، وزر تحديث فوري.
- تعديل عناوين الأقسام ووصفها وترتيبها وإظهارها/إخفاؤها، واختيار مجلد كل قسم.
- إضافة الإنجازات وتعديلها وترتيبها وربطها بشواهدها.
- إخفاء أي وثيقة عن الزوار دون حذفها من Drive.
- إضافة الوثائق تتم برفعها إلى مجلد Drive، فتظهر في الموقع تلقائيًا دون إعادة تصميم.
