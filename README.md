# موقع د. أفنان الطلحي التعليمي

موقع تعليمي تفاعلي باللغة العربية (RTL) يحوّل العروض التعليمية إلى تجارب رقمية: دروس تفاعلية، ومختبرات افتراضية ثلاثية الأبعاد، ومسابقات للمجموعات، ولوحة تحكم خاصة لإدارة المحتوى.

## ما الذي يحتويه الموقع؟

| القسم | الرابط | الوصف |
|---|---|---|
| الصفحة الرئيسية | `/` | واجهة ترحيبية بنموذج DNA ثلاثي الأبعاد، والدروس، والمختبرات، والمسابقات، والأعمال، والتواصل |
| مكتبة الدروس | `/lessons` | كل الدروس مع البحث والتصفية حسب الصف |
| درس علم الوراثة | `/lessons/genetics` | تحويل كامل لعرض «علم الوراثة» (56 شريحة) إلى 8 أجزاء تفاعلية |
| المختبرات الافتراضية | `/labs` | مربع بانيت، التزاوج عبر الأجيال، الكروموسومات و DNA ثلاثية الأبعاد، تحديد الجنس، السيادة غير التامة، مخطط السلالة |
| المسابقات | `/games` | مسابقة مجموعات بالنقاط والمؤقت والمؤثرات الصوتية ولوحة الترتيب وشاشة الفوز |
| معرض الأعمال | `/portfolio` | الأعمال والعروض |
| طلب تصميم | `/request` | نموذج يصل إلى لوحة التحكم |
| لوحة التحكم | `/admin` | محمية بكلمة مرور |

### درس علم الوراثة (من العرض الأصلي)
1. **التهيئة والتقويم القبلي:** قوانين الصف، الأهداف، بطاقات المفردات المقلوبة، لغز «صفة تختفي ثم تعود»، تقويم صح/خطأ بتغذية راجعة فورية.
2. **الوراثة والجينات المتقابلة:** مختبر كروموسومات ثلاثي الأبعاد (تدوير وتكبير وتغيير الأليلات)، ومحاكاة الانقسام المنصّف والإخصاب.
3. **تجارب مندل:** خط زمني بالكشف التدريجي، الصفات السبع، الصفة النقية والهجين، محاكاة الأجيال الثلاثة P → F1 → F2.
4. **السائد والمتنحي:** شرح + أداة اختيار الجينين ونمو النبات.
5. **الطرز الجينية والشكلية:** محاكاة الاحتمالات بقطعة النقد، انفوجرافيك TT / Tt / tt، نبات فم السمكة.
6. **مربع بانيت:** الخطوات، مربع بانيت تفاعلي (7 صفات، اختيار الأليلات، عرض متحرك أو «توقّعي أولًا»)، حل تمرين القطط خطوة بخطوة، مبادئ علم الوراثة.
7. **المحاكاة والأنشطة:** التزاوج عبر الأجيال، السيادة غير التامة، تحديد جنس المولود، مخطط السلالة، بطاقات الواقع، نموذج DNA، خريطة مفاهيمية وشكل فن (محلول + نشاط بالتصحيح)، الربط بالدين والوطن والإثراء.
8. **التقويم النهائي:** تدريبات نافس بالمؤقت، لوحة نجمات العلوم، حل التمارين، التقويم الختامي، الخلاصة، الأوسمة القابلة للطباعة، الواجب.

مفتاح **«ملاحظات المعلمة»** أعلى الدرس يُظهر ملاحظات الشرائح الأصلية. أسماء الطالبات في لوحة النجوم والأوسمة تُحفظ على جهاز المعلمة فقط ولا تُرسل للخادم.

### لوحة التحكم
- إضافة الدروس وتعديلها وحذفها (أقسام، غلاف، نشر/مسودة).
- رفع ملفات PowerPoint وPDF والصور والفيديو وربطها بالدروس (تُعرض داخل صفحة الدرس).
- مكتبة الملفات.
- إنشاء الاختبارات؛ كل اختبار يصبح مسابقة مجموعات تلقائيًا.
- تعديل النصوص والألوان ووسائل التواصل.
- استقبال طلبات العملاء وتغيير حالتها.
- إدارة معرض الأعمال.

## التقنيات
Next.js 14 (App Router) + TypeScript • Tailwind CSS • Framer Motion • Three.js + React Three Fiber • Prisma + PostgreSQL • Vercel Blob لرفع الملفات • خط المراعي.

## التشغيل على جهازك
```bash
npm install
cp .env.example .env        # ثم عدّلي القيم
npm run db:local            # (اختياري) قاعدة بيانات PostgreSQL محلية دون تثبيت — في نافذة مستقلة
npm run db:push             # إنشاء جداول قاعدة البيانات
npm run dev                 # http://localhost:3000
```
عند استخدام `db:local` اجعلي `DATABASE_URL="postgresql://afnan:afnan@localhost:5433/afnan"`.
بدون Vercel Blob تُحفظ الملفات المرفوعة محليًا في مجلد `uploads/`.

## النشر على Vercel
1. من [vercel.com/new](https://vercel.com/new) استوردي المستودع `afnan-site`.
2. من تبويب **Storage** في المشروع:
   - أنشئي قاعدة **Postgres** (Neon) واربطيها بالمشروع ← يُضاف `DATABASE_URL` تلقائيًا.
   - أنشئي **Blob Store** واربطيه ← يُضاف `BLOB_READ_WRITE_TOKEN` تلقائيًا.
3. من **Settings ← Environment Variables** أضيفي:
   - `ADMIN_PASSWORD` كلمة مرور لوحة التحكم.
   - `AUTH_SECRET` نص عشوائي طويل (32 حرفًا أو أكثر).
   - `NEXT_PUBLIC_SITE_URL` رابط موقعك.
4. اضغطي **Deploy**. أمر البناء `vercel-build` ينشئ جداول قاعدة البيانات تلقائيًا.
5. ادخلي إلى `/admin` بكلمة المرور.

> لا تضعي أي كلمات مرور أو مفاتيح داخل المستودع؛ ملف `.env` مستثنى من Git.
